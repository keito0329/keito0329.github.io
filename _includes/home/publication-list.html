{% comment %} Renders the _publications collection as one flat numbered list, newest first. The Publications page groups by category instead; both render each entry with home/publication-item.html so they cannot drift apart. Parameters: lang - "ja" to label the links in Japanese, anything else uses English. domestic - true to include papers in the "domestic" category. When false they are left out, which keeps the English front page readable. more - true to append a link to the full Publications page.
