{% comment %} Renders a single publication as a list item. Shared by the lists on the front page and the CV (home/publication-list.html) and by the Publications page, which groups by category, so all three stay identical. The `authors` field is Markdown. A name wrapped in **bold** is rendered bold and underlined, marking a lead-authored paper. The optional `venue_short` field is shown as a badge before the title, for example "SIGIR 2026". Leave it out and no badge appears, which is a way to highlight only the venues worth calling out. Parameters: publication - one entry of the _publications collection. lang - "ja" to label the links in Japanese, anything else English. Usage: {% include home/publication-item.html publication=post lang="ja" %} {% endcomment %} {% include base_path %} {%- assign publication = include.publication %}
